One-time setup

In this repo's Settings → Secrets and variables → Actions, add:

  • SMTP_USERNAME — the sending email address (e.g. a Gmail address)
  • SMTP_PASSWORD — an app password for that account (not your regular password)
  • EMAIL_TO — where alerts should be delivered
  • SMTP_SERVER / SMTP_PORT — optional, default to smtp.gmail.com / 587

Then edit finance-agent/config.json (using the editor above to generate it) to add tickers and set the interval. You can trigger a check immediately from the Actions tab → "Finance Notification Agent" → "Run workflow" instead of waiting for the schedule.
